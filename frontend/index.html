SDK & Gateway Integration Guide

Download SDK Package (GitHub Release)

Clear, step-by-step developer guide to connect any LLM Gateway to the Governance Tracker in under 2 minutes.

Step 1

Download SDK

Get the official governance-interceptor-v1.0.0.zip package directly from GitHub Releases CDN.

Download SDK (.zip)
Step 2

Installation

Install the interceptor directly into your gateway virtual environment via pip:

pip install governance-interceptor

Or install from local zip package:

pip install governance-interceptor-v1.0.0.zip
Step 3

Configuration

Set your Tracker endpoint URL and API key environment variables:

TRACKER_URL="https://model-substitution-governance-event.onrender.com" API_KEY="usr_live_your_api_key_here"
Step 4

Import & Intercept

Attach the interceptor right after your gateway selects the target model:

from governance_interceptor import GovernanceInterceptor interceptor = GovernanceInterceptor(tracker_url=TRACKER_URL) # After routing decision: interceptor.intercept( requested_model="GPT-5", actual_model="GPT-4o Mini", reason="cost", agent_id="HR-Agent", session_id="session-102" )
Step 5

Gateway Routing Architecture Flow

Lifecycle flow of requests between your gateway and the Governance Tracker:

Client Application Request (e.g. Requested Model = "GPT-4") │ ▼ LLM Gateway Routing Engine (Cost / Availability / Policy Rules) ├── Selects Actual Model (e.g. "Gemini 1.5 Flash") │ ▼ Governance Interceptor SDK (POST /api/v1/events with X-API-Key) │ ▼ Governance Tracker & Dashboard (Recorded under your User Profile) │ ▼ Provider LLM API (OpenAI / Anthropic / Google Gemini)

📖 Developer Integration & Setup Walkthrough

Overview: Connecting your LLM application or gateway to the Governance Tracker requires zero backend refactoring. The Interceptor SDK observes routing decisions and posts substitution events directly to your personal account.

Step 1: Get Your Account API Key

Log in to your dashboard and copy your Developer API Key from the top of the Integration tab. If you need a fresh raw key secret, click Regenerate Key to generate and copy a new secret.

Step 2: Add API Key to Your App Environment

Open your application's .env file (e.g., in your FastAPI, Next.js, or Python backend) and add your API key:

TRACKER_URL="https://model-substitution-governance-event.onrender.com" API_KEY="usr_live_your_copied_key_here"

Step 3: Install & Call the Interceptor

In your gateway routing logic, import the interceptor and call intercept() whenever a model substitution occurs:

from governance_interceptor import GovernanceInterceptor interceptor = GovernanceInterceptor() # When your gateway routes or substitutes a model: interceptor.intercept( requested_model="GPT-4o", actual_model="Gemini 1.5 Flash", reason="cost", # 'cost', 'availability', or 'policy' agent_id="Document-Analyzer-Agent", session_id="document-upload-001" )

Step 4: Verify Live Events on Dashboard

Run your application and scan a document or execute an LLM prompt. Switch back to this dashboard and open the Governance Event Recorder tab (or click Refresh). Your event will immediately populate in the real-time table!
