SDK & Gateway Integration Guide

Download SDK Package (GitHub Release)

Follow these steps to install the lightweight interceptor library into your LLM gateway service and automatically send model substitution events to your tracker.

SDK Distribution Model: Distributed via GitHub Releases (Global CDN) for instant versioned downloads with zero backend cold-start latency.
Latest Version: v1.0.0 | Distribution: GitHub Releases
The FastAPI backend is reserved exclusively for high-throughput governance APIs (events, risk calculation, compliance audit).
Step 1

Download SDK

Get the official governance-interceptor-v1.0.0.zip package directly from GitHub Releases CDN.

Download SDK (.zip)
Step 2

Installation

Install the interceptor directly into your gateway virtual environment via pip:

pip install governance-interceptor

Or install from local wheel package:

pip install governance-interceptor.whl
Step 3

Configuration

Set your Tracker endpoint URL and optional API key environment variables:

TRACKER_URL="https://model-substitution-governance-event.onrender.com" API_KEY="your-enterprise-api-key"
Step 4

Import & Intercept

Attach the interceptor right after your gateway selects the target model:

from governance_interceptor import GovernanceInterceptor interceptor = GovernanceInterceptor(tracker_url=TRACKER_URL) # After routing decision: interceptor.intercept( requested_model="GPT-5", actual_model="GPT-4o Mini", reason="cost", agent_id="HR-Agent", session_id="session-102" )
Step 5

Gateway Routing Flow

Execution lifecycle between your gateway and the Cloud Tracker:

Client Request ↓ Requested Model = GPT-5 ↓ Routing Engine → Actual Model = GPT-4o Mini ↓ Governance Interceptor (POST /api/v1/events) ↓ Call Provider API (OpenAI / Claude / Gemini)

Module Overview

Enterprise System Architecture

Developer │ ▼ GitHub Releases (Global CDN) │ ├── Download Governance Interceptor SDK (v1.0.0) ├── Download Sample Gateway (v1.0.0) │ ▼ Install into Enterprise LLM Gateway │ ├── Routing Decision Made (Requested != Actual) ├── POST /api/v1/events (Async / Non-blocking) │ ▼ Governance Tracker Cloud APIs (Hosted on Render) ├── Ingestion & Validation Router ├── Risk Assessor Engine (Context Window Drop Analysis) ├── Compliance Flag Engine (Agent Whitelist Policy Match) │ ▼ PostgreSQL Relational Storage (Hosted on Supabase) │ ▼ Enterprise Governance Dashboard (Hosted on Vercel)

Enterprise Architecture Overview

• SDK Distribution: Distributed via GitHub Releases for instant CDN downloads, versioning, and zero backend cold-start latency.
• Governance Tracker APIs: High-throughput FastAPI cloud backend on Render reserved exclusively for governance event ingestion and compliance audits.
• Database (Supabase PostgreSQL): Enterprise relational database storing model specs, agent policies, and immutable substitution logs.
• Web Dashboard (Vercel): Real-time monitoring UI displaying live event streams, capability risk alerts, compliance flags, and retroactive audit reports.
