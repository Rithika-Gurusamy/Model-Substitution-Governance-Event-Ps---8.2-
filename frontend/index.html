SDK & Gateway Integration Guide

Download SDK Package (GitHub Release)

Follow these steps to install the lightweight interceptor library into your LLM gateway service and automatically send model substitution events to your tracker.

Step 1

Download SDK

Get the official governance-interceptor-v1.0.0.zip package directly from GitHub Releases CDN.

Download SDK (.zip)
Step 2

Installation

Install the interceptor directly into your gateway virtual environment via pip:

pip install governance-interceptor

Or install from local wheel package:

pip install governance-interceptor.whl
Step 3

Configuration

Set your Tracker endpoint URL and optional API key environment variables:

TRACKER_URL="https://model-substitution-governance-event.onrender.com" API_KEY="your-enterprise-api-key"
Step 4

Import & Intercept

Attach the interceptor right after your gateway selects the target model:

from governance_interceptor import GovernanceInterceptor interceptor = GovernanceInterceptor(tracker_url=TRACKER_URL) # After routing decision: interceptor.intercept( requested_model="GPT-5", actual_model="GPT-4o Mini", reason="cost", agent_id="HR-Agent", session_id="session-102" )
Step 5

Gateway Routing Flow

Execution lifecycle between your gateway and the Cloud Tracker:

Client Request ↓ Requested Model = GPT-5 ↓ Routing Engine → Actual Model = GPT-4o Mini ↓ Governance Interceptor (POST /api/v1/events) ↓ Call Provider API (OpenAI / Claude / Gemini)
